Fact sheet

Short description

Help Akeme, a tiny knight, climb an endless cursed tower. Fast, precise arcade jumping with a daily challenge, a sprint mode and unlockable colors.

About the name

Akeme is pronounced ah-KEH-mee. The name blends the names of the developer's family.

Ayuda a Akeme, un pequeño caballero, a escalar una torre maldita sin fin. Saltos arcade rápidos y precisos, con reto diario, modo sprint y colores desbloqueables.
